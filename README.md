# Sales Performance Dashboard using Power BI

## Project Overview
This project focuses on analyzing sales performance using Microsoft Power BI. The dashboard provides insights into sales, profit, orders, product categories, regions, customer segments, and monthly sales trends.

## Objectives
- Analyze overall sales and profit performance.
- Track important business KPIs.
- Compare sales across categories and regions.
- Analyze monthly sales trends.
- Understand sales contributions from different customer segments.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- Sample Superstore Dataset

## Key Features
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin %
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Sales by Segment
- Interactive filters for Region, Category, and Segment

## Project Workflow
1. Imported the dataset into Power BI.
2. Reviewed and prepared the data.
3. Created a Calendar table and date relationship.
4. Developed DAX measures for KPIs.
5. Created charts and interactive filters.
6. Designed and tested the dashboard.

## Key Insights
The dashboard helps users compare sales performance across categories, regions, customer segments, and months. It supports identifying high- and low-performing areas and making data-driven business decisions.
